# The 13th Door
### A Psychological Mystery Puzzle-Adventure Game Concept

## About the Project

**The 13th Door** is an original first-person psychological mystery puzzle-adventure game concept based on memories, identity, guilt and reality.

The story follows Alex, who wakes up inside an unfamiliar mansion with twelve mysterious doors. Each door leads to a different memory environment containing hidden objects, puzzles and clues connected to the protagonist's forgotten past.

Players must explore the mansion, solve puzzles, collect memory fragments and uncover the truth behind the mysterious thirteenth door.

## Key Features

- **12 Memory Environments:** Explore different locations connected to forgotten memories.
- **Mystery Storytelling:** Discover secrets through environmental clues.
- **Puzzle Solving:** Solve logical and interactive puzzles.
- **Hidden Objects:** Find photographs, letters, keys and other important objects.
- **Changing Environments:** Experience mysterious changes throughout the mansion.
- **Memory Journal:** Review collected clues and discoveries.
- **Multiple Endings:** Player decisions influence the proposed story outcomes.

## Main Characters

- **Alex:** The protagonist who investigates the mysterious mansion.
- **Mira:** Alex's younger sister, connected to the central mystery.
- **The Stranger:** A mysterious figure who leaves cryptic messages.

## Gameplay Mechanics

1. Explore the mysterious mansion.
2. Enter different memory environments.
3. Search for hidden objects and clues.
4. Solve environmental puzzles.
5. Unlock new memories.
6. Connect discoveries to understand the mystery.
7. Unlock the hidden thirteenth door.
